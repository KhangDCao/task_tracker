# Task Tracker
Task Tracker is a simple command-line interface (CLI) to manage your everyday tasks.
## Features
- Add tasks
- Update tasks
- Delete tasks
- Mark tasks as in progress
- Mark tasks as done
- List tasks
- List todo tasks
- List in-progress tasks
- List finished tasks
## Usage
Add a task
```
python main.py add "Buy groceries"
```
Update a task
```
python main.py update 1 "Buy milk and beef"
```
Delete a task 
```
python main.py delete 1
```
Mark tasks as in progress
```
python main.py mark-in-progress 1
```
Mark tasks as done
```
python main.py mark-done 1
```
List tasks
```
python main.py list
```
List todo tasks
```
python main.py list todo
```
List in-progress tasks
```
python main.py list in-progress
```
List finished tasks
```
python main.py list done
```
